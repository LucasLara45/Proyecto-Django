# Fresh Side

Sitio web de refrigeración desarrollado con Django.

## Funciones

- Registro e inicio de sesión
- CRUD de servicios y productos reacondicionados
- Sistema de reseñas
-
- Diseño responsive
- Panel administrativo

## Tecnologías

- Python
- Django
- HTML
- CSS
- SQLite

## Instalación

```bash
git clone URL
cd refrig
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
